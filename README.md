# 90+ Store - Catálogo Inteligente ⚽️👕

O **90+ Store** é uma plataforma de catálogo interativo desenvolvida para revolucionar a venda de camisas de time e streetwear. O projeto foca em alta conversão e baixo custo operacional, utilizando o conceito de "Catálogo Wildcard" para integrar navegação web de alta performance com fechamento de vendas via WhatsApp.

---

## 🚀 Visão Geral
Este projeto foi criado para resolver a fricção de vendas em marketplaces tradicionais. Em vez de atendimentos manuais repetitivos, o sistema oferece uma vitrine profissional onde o cliente seleciona múltiplos produtos, e a plataforma gera um pedido estruturado para finalização humanizada.

## 🛠️ Tecnologias Utilizadas
- **Framework:** [Next.js 15+](https://nextjs.org/) (App Router & Server Components)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/)
- **Backend/Database:** [Supabase](https://supabase.com/) (PostgreSQL)
- **Linguagem:** [TypeScript](https://www.typescript.org/)
- **Deploy:** [Vercel](https://vercel.com/) (Em breve)

## 🎯 Funcionalidades Principais
- [x] **Integração em Nuvem:** Conexão em tempo real com banco de dados PostgreSQL via Supabase.
- [x] **Design Moderno:** Interface "Mobile First" focada no público jovem e fãs de futebol.
- [x] **Carrinho Inteligente:** Seleção de múltiplos itens com soma automática (Em progresso).
- [x] **Integração WhatsApp:** Geração de deep-links para checkout direto (Em progresso).
- [x] **Painel Administrativo:** Gestão de estoque e disponibilidade (Em progresso).
